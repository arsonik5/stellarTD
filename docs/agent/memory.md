# Memory policy

Save only durable deltas that prevent repeated work: invariant, recurring failure, required command, or user preference.

Format: `fact => consequence; pointer`.

Use compact English/ASCII. Do not assume Mandarin, emoji, or Unicode symbols reduce Claude tokens; measure with the active model's tokenizer. Keep `MEMORY.md` an index of short pointers; detail belongs in on-demand topic files. Replace stale notes; do not append progress logs or duplicate tracked docs.
