# Low-token workflow

Default: targeted inspect -> edit -> smallest validation -> concise handoff.

- Start with exact path/symbol search; read ranges, not whole trees, docs, or logs.
- Keep one main agent for coupled work. Use built-in Explore for isolated reconnaissance likely to flood context; request only findings, paths, and decisions.
- Use agent teams only for genuinely independent parallel work; each teammate duplicates startup context and token cost.
- Use medium effort by default. Use low only for listing/searching; elevate only for hard design/debugging.
- Do not add output styles, prompt hooks, or imports solely for brevity: they add always-on prompt tokens. Use `CLAUDE.md` for the compact rule; use this file on demand.
- Memory write test: would a future session repeat meaningful work without it? If no, write nothing. If yes, update one topic note and its index pointer.
