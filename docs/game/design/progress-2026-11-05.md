## Decisions made on Michael's behalf

- **Death costs time, not items** (open decision 3): respawn at the nearest respawn beacon, else the landing spot.
- **Deposits are finite per drill site** (open decision 2): a drill exhausts its 5-shaft pit and must be moved.
- **Power is a boost, not a gate**, for ordinary machines: unplugged they run at base speed, powered x2.
  Only `needs_power` buildings (containment field) stop without power. Keeps the early game playable.
- **Raiders are force-driven rigid bodies**, not block-built Ships: they obey gravity and collisions but arrive
  assembled. Player ships and the scout keep the Ship system.
- **Turret ranges raised** (gun 14 -> 55 m, cannon 20 -> 80 m) and rounds sped up (45 -> 140, 30 -> 110 m/s):
  the old numbers could not reach anything flying.
- **Research gates** the drill, crusher, uplink, power, cannon, reactor and containment; points come only from
  doing things for the first time, so exploring the economy is what unlocks it.
- **Raids can be switched off** (Settings > Gameplay > Raids): pure-builder players keep scouts and signature but
  no waves. Default Normal.
- **Foundations are walls**: they now have structure (200 + 400 x height), so drones cut through what blocks them.
- **The 0.25 m mechanism grid is deferred**: joints shipped on the existing 0.5 m grid; halving the grid means
  doubling every part's size and a save migration - the riskiest change, left for a session with Michael.

## Known gaps (honest list)

- Pipes/merger/splitter still use world-axis cardinal directions (works near the spawn pole, not everywhere).
- Drones walk straight at targets and hop when blocked - no pathfinding; walls slow them, they do not stop them.
- No world audio (drill, machines, turrets) - UI sounds only. Icons for new items are glyphs (no Blender here).
- All new buildings are BLOCKOUT models built in code (`world/blockout.gd`), each part with a job; replace with
  Blender models when the art pass reaches them.
- Logic wires, robot cores and behaviour cards (rest of C5) not started.
- Terrain edits (drill, craters) only happen where terrain is streamed in near the player.
- Four dev scripts were already broken before this session (lint lists them in `KNOWN_BROKEN`).
- Pushing to GitHub is still blocked (403): everything is committed locally on `design/whole-game-pass`.
