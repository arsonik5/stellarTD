# Design pass (2026-11-04)

Whole-game design, top down. Read in order the first time; afterwards load only the layer you need.

| File | What it decides |
|---|---|
| `01-vision.md` | premise, fantasy, pillars, arcs, what the game is not |
| `02-core-mechanics.md` | the loop and the 10 core mechanics, status vs code, the three nested grids, robots |
| `03-minor-mechanics.md` | supporting systems (M1-M36) grouped by the core mechanic they serve |
| `04-small-things.md` | feedback per action, QoL, world feel details |
| `05-planets.md` | why planets aren't good yet, NMS/SE2 lessons, target planet architecture, study checklist |
| `06-architecture.md` | services, components, damage contract, constructs, threat AI, perf, tests |
| `07-roadmap.md` | economy audit, milestones G1-G6 and W1-W6, open decisions |

Rule: a mechanic that does not trace back to a pillar in `01-vision.md` waits.
